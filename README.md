# GTM Buddy Extension Demo

Interactive demo of the GTM Buddy browser extension: a sales rep's inbox and calendar with Meeting Prep, recommended content, email templates and Nucleus, plus guided tours and an optional voice-over.

It is a static site. `index.html` is self-contained, with no build step and no dependencies.

## Deploy on Vercel

1. Push this folder to a GitHub repo.
2. In Vercel, click **Add New > Project** and import the repo.
3. Leave **Framework Preset** as **Other**, and leave the build command and output directory empty.
4. Click **Deploy**.

## Run locally

Open `index.html` in a browser.
